# M6 确定性安全排版实施报告

日期：2026-09-21。版本：0.13.0。

## 已实现

- 新增格式计划与格式报告契约，并导出 JSON Schema。
- 新增缩略词表三线表适配器，使用 OOXML 的八分之一磅单位写入边框。
- 将 4 条已有用户确认记录的规则从 `read_only` 升级为专用适配器、`auto_fixable=true`；未确认规则仍由契约禁止自动修复。
- 新增 CLI、任务 API、下载接口和前端确认卡。排版请求可重复读取同一结果，不生成多个不可追踪副本。
- 输出前后重新解析 DOCX 并比较内容指纹；不一致时不交付文件。

## 合成验收

一个无边框的两行缩略词表被格式化为顶线 1.5 pt、表头线 1 pt、底线 1.5 pt、无竖线；格式化前后内容指纹一致，原文件字节不变。测试同时覆盖部分规则批准、结构歧义、阻断对象和输出覆盖拒绝。

完整回归为 145 项后端测试、Ruff、严格 mypy（69 个源文件）、Schema 同步、前端类型检查、Vitest 与生产构建全部通过。两条 TestClient 第三方弃用警告不影响功能。

## 真实论文边界

真实论文是否存在可无歧义定位的缩略词表，要以其 M3 结果为准。本阶段不对真实论文批量写入，因为 244 条规则仍为暂定，且真实 Gold Set 尚未完成人工标注。M6 的“完成”指安全排版基础设施与首个已确认规则适配器完成，不代表学校全部格式已自动化。

## 下一模块

M7 将对生成副本执行 OOXML 再验证、内容保护检查、可选 Word/LibreOffice 打开与 PDF 渲染探测，并生成用户逐项检查清单与交付清单。
