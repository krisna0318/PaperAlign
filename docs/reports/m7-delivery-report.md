# M7 Word 验证与交付实施报告

日期：2026-09-21。版本：0.14.0。

## 完成内容

- 新增交付验证契约、规则复检记录、Word 探测结果和交付就绪状态。
- 新增静态交付服务，重新验证输入/输出身份、内容指纹、包安全与 4 条已应用规则。
- 新增可选 Windows Word COM 适配器，采用隐藏、只读打开，执行重分页与 PDF 导出；没有 Word 时安全降级。
- 新增 CLI `validate-delivery`、任务 API、检查单/PDF 下载接口和前端最终验证面板。
- 新增固定人工清单，任何自动化结果都不能取消人工视觉验收。

## 当前机器实测

合成缩略词表通过静态交付闸门。当前机器未发现 `WINWORD.EXE` 或 `soffice.exe`，COM 探测返回 `COMException`，系统输出 `word_render.status=unavailable` 且不生成 PDF。这证明降级路径有效，不证明真实论文在 Word 中的视觉效果。

全量回归为 148 项后端测试、Ruff、严格 mypy（72 个源文件）、Schema 同步、前端类型检查、Vitest 与生产构建全部通过。浏览器在 1280×720 下正确显示 0.14.0/M7、上传入口，无横向溢出且控制台无警告或错误；浏览器工具未能把本地合成文件附加到文件选择器，因此上传后的页面流程以 API 集成测试覆盖，仍列入用户验收清单。

## 范围结论

M0—M7 的 MVP 工程链路已经闭合：模板/Profile → 只读解析 → 结构识别 → 受控 AI 建议 → 三模式评测 → 本地诊断 UI → 已确认规则的确定性新副本 → 静态/Word/人工交付闸门。

产品能力仍受证据约束：只有 4 条缩略词表边框规则可自动修复，244 条规则保持暂定；真实 28 项 Gold Set 尚无人工标签。因此不能宣传为“全论文一键排版”或给出未验证准确率。
