# M5 本地只读诊断界面实施报告

日期：2026-09-21。版本：0.12.0。

## 完成内容

- 新增 `/api/jobs` 创建接口与 `/api/jobs/{id}` 查询接口，使用原始请求体上传，避免额外表单解析依赖。
- 每个任务拥有独立输入、产物和 `job.json`；使用临时文件原子替换，原稿从不作为输出目标。
- 新增稳定的诊断摘要契约，保留输入 SHA-256、内容指纹、角色计数、验证计数、不支持对象、待确认入口和规则定位。
- 页面提供拖放上传、连接状态、诊断指标、待确认结构与格式证据；移动端布局和减少动画偏好已覆盖。
- 大文档接口最多返回 100 条异常证据，明确不一致优先；完整结果仍保留在本地结构报告。

## 安全与产品说明

M5 固定使用 Rules-only，不读取或发送 API Key。前端不展示整篇正文，待确认预览最长 20 字。页面固定声明“只读诊断，不是整篇论文合规证明”，最终分页、目录域、图表位置和特殊对象仍需桌面版 Word 复核。

后端 139 项测试通过，Ruff 与严格 mypy 通过；前端 TypeScript 检查、Vitest 和生产构建通过。Vite 在默认沙箱因 Windows 上级目录读取限制失败，获得执行授权后在同一工作区构建成功；这不是项目代码错误。浏览器人工视觉验收留给最终逐项清单。
