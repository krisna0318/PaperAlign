# M4.4 三模式评测收口报告

日期：2026-09-21。代码基线：0.11.0。

## 收口结论

Rules-only、model proposal 和 Hybrid 已能在同一份 Gold Set 契约上评测，计划、模型运行、Hybrid 结果和标签均通过输入哈希、内容指纹及目标 ID 绑定。当前真实模板含 28 个目标，但人工确认标签为 0，因此三种系统的准确率、Precision、Recall 和 F1 均为“未评估”。

这不是测试失败，而是证据边界：模型自己的答案不能成为 Gold Set，启发式置信度也不能替代人工标签。现阶段可以确认的是运行链路、覆盖率、人工复核量、Token 与耗时记录；不能确认哪个系统更准确。

## 当前可以进入后续阶段的内容

- M5 可以读取已有结构报告，展示只读诊断、待确认入口、明确不一致和证据不足。
- M6 可以开发确定性排版引擎，但只能处理已确认、可安全定位、可自动修复的规则，并默认使用合成样本验证。
- Hybrid 的 5 个策略自动接受结果不得直接授权排版；在 Gold Set 校准前仍视为待产品验收。

## 发布门槛

要把 Hybrid 策略从 `provisional_not_accuracy_validated` 升级，必须逐项完成人工 Gold Set，并重新运行三模式评测。报告至少需要给出已标注样本量、各角色支持量、弃权、冲突、错误样例和置信区间；样本不足时继续显示“证据不足”。

## M4 最终状态

M4 的工程链路已完成，质量校准未完成。后续开发可以继续，但对外演示必须把“链路可用”和“准确率已验证”分开陈述。
