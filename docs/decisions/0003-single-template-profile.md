# ADR 0003：先贯通一个华农本科模板

日期：2026-09-20。状态：已确认适用范围，原子规则分状态审查。

## 决定

按用户本次确认，现有模板用于华南农业大学当前应届本科毕业生，排除外国语学院和研究生。本轮不扩展其他学校模板，也不开发学院定制规则。

“当前应届”以本次确认日期为锚点，内部标识为 `current_graduates_at_2026-09-20`；未擅自推断为某个具体毕业年份。既有 Profile ID `scau_undergraduate_2026_v1` 保留兼容，不代表自动适用于未来届别。

这一确认解决的是模板适用范围，不等于用户已经逐项审核全部原子规则。确定性开发可以继续；暂定规则不得产生“学校合规已通过”的结论。

## 证据与实现

- 学校明确批注或书面规范优先；无明确要求时使用模板实际设置作为暂定证据。
- 规则配置绑定模板 SHA-256；正式模板及论文原稿留在被忽略的本地目录。
- 规则、证据索引、覆盖清单和适用范围分别保存，避免把“代码支持”混同于“规范确认”。
- 已定位模板样本只用于验证链路，不把模板段落序号套用到用户论文。
- 页面、表格、段落等单值比较先落地；语义识别、分页效果、自动排版按后续里程碑实施。

## 既有表格边框确认

延续此前用户“按理来说应该按照批注要求来，但如果有的学校没有批注，那就按照实际设置来”的选择，缩略词表采用批注要求：顶线和底线 1.5 pt、中间分隔线 1 pt、无竖线。仅这四条延续为已确认规则，不将该选择扩大为其余规则的逐条确认。

真实模板缩略词表中间线实际为 0.5 pt。验证应如实报告差异；不能为了让官方模板全部通过而把规则改成 0.5 pt。

## 仍待确认，但不阻碍只读开发

页码开始位置和分区、无批注的页面设置是否具规范性、跨页及“空一行”的等价方式、参考文献专项规范等保持暂定或延期。未确认之前不据此自动修改文件。

## 本阶段完成的定义

单模板配置可装载、证据可追溯、适用范围能判定、已定位样本可返回真实差异或明确的不确定状态。此定义不等于整篇论文自动排版完成。
