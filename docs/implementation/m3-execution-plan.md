# M3 执行方案：论文结构识别与人工纠正

日期：2026-09-20。状态：核心流程已实现并通过真实样本与完整工程回归。目标：让现有华农模板规则可以关联到论文原稿中的真实对象，为后续诊断和排版提供可审查的结构结果。

## 范围与顺序

1. 保持 M1 解析结果和内容指纹不变，另建结构判定报告；原始稿件只读。
2. 提取正文层段落的标题样式、大纲级别、文字编号、目录域和危险对象信号。统一使用既有定位器，不使用模板固定序号。
3. 实现 Rules-only 顺序识别：前置部分、中文/英文摘要、关键词、目录、四级标题、正文、图表题、参考文献、附录、致谢。用冲突和低置信候选表示歧义，不由字体大小单独断定标题。
4. 构建章节归属与层级检查；目录项不进入正文章节树；段落或表格不遗漏、不重排。
5. 支持绑定输入哈希的人工角色纠正，记录审查人和原因，重新计算后续区域与层级。提供本地结构审查 HTML、JSON 和 Markdown，不复制全文。
6. 将可靠定位的对象接入 M2 比较器；剩余目标选择器或布局规则保留明确状态，不自动升级规则确认。
7. 用合成正反例、真实模板及论文原稿验证，记录边界与后续路线；不以“识别数量”冒充准确率。

## 当前 M2 未完成项如何处理

248 条规则中 244 条仍暂定，页码区域、目录与续表关系等存在语义/布局依赖。它们登记在覆盖清单中，M3 提供对象定位基础；不阻断结构识别开发，也不据此宣称 M2 全量规范验收完成。

## 验收

- 同输入、同配置重复输出一致；输入 SHA 和内容指纹不变。
- 每个 M1 文档块恰好有一条结构判定，含原定位、依据与确认状态。
- 目录域跨段落、目录样式、普通编号列表、标题级别冲突、参考文献和附录均有独立回归样本。
- 人工纠正拒绝错误文档哈希、未知/重复 block ID 和不合法角色；不静默覆盖为学校规则确认。
- 审查结果默认无文本预览，可显式启用每项最多 20 字；输出限制在本地被忽略的 `.paperalign`。
- 原文中的活动内容和未解析结构不被默认为可安全排版；M3 不生成排版后的 DOCX。

## 距离单模板完整 MVP 的剩余阶段

| 阶段 | 用户可见交付 | 完成条件 |
|---|---|---|
| M3 结构识别（本轮） | 看到每段属于什么，能纠正错误识别 | 可追溯、有层级、可重复，有边界样本验证 |
| M4 AI 与对照评测 | 歧义项可请求 AI 建议，无密钥仍可使用规则流程 | 输出校验、失败降级、token/耗时记录、同样本对照 |
| M5 诊断界面 | 上传、选模板、审查结构与格式问题、确认规则 | 完成从文件输入到确认记录的本地交互 |
| M6 确定性排版 | 导出格式调整后的副本、改动清单 | 仅修改获准格式，内容指纹及受保护对象校验通过 |
| M7 Word 最终验收 | 可在 Word 打开、完成目录页码并检查分页 | 原稿可恢复、幂等、Word 页面人工验收及真实样例回归 |

先保持一个模板、一个本地流程，复用现有解析器和规则比较器，减少每阶段重建数据结构。五个阶段是能力边界，不必等同五次开发会话；当前没有足够测量依据给出精确剩余工时或完成百分比。
