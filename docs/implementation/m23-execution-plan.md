# M2.3 单模板 Profile 执行方案

日期：2026-09-20。

用户已确认使用现有华农本科模板：适用于当前应届本科毕业生，排除外国语学院及研究生；本轮只做这一份模板，不扩展学院定制或其他学校。

1. 增加 Profile manifest、适用范围、证据索引和 P0 覆盖清单模型。
2. 把 P0 中明确的格式要求拆成原子规则，分组保存 JSON；标签/正文、首段/后续段使用显式目标选择器。
3. 建立安全、确定性的规则装载器，检查重复 ID、Profile/模板哈希、证据引用、覆盖映射及矛盾定义。
4. 提供 CLI 导出 Profile 审查报告及适用范围判断，正式 Profile 随安装包分发。
5. 接入已定位对象的只读规则验证（M2.4 基础），完成模板表格边框的端到端对照；未确认规则及不支持对象仍遵循 M2.2 状态约定。
6. 以合成正反例、真实模板、完整回归验证结果，更新报告及 CONTEXT。

本轮不会把“模板适用范围已确认”写成“用户逐条确认了所有格式规则”。既有已确认缩略词表规则保持 confirmed；其他规则可正常装载但保留审查状态。页码边界、图表跨页及语言学要求以待复核项登记，不编造期望值，也不自动修改文档。

验收：P0 每一行均有规则映射或明确的未实现原因；全部 JSON 通过模型及 Schema；外国语学院/研究生不匹配；同输入导出一致；已确认缩略词表中间线应报告实际 0.5 pt 与要求 1 pt 的差异。
