# M5 执行方案：本地只读诊断界面

日期：2026-09-21。状态：已完成。

## 一句总结

让用户上传一个 DOCX，在不修改原文、不依赖 API Key 的前提下看到文档画像、待确认结构、格式证据和限制说明。

## 模块边界

M5 只负责创建本地任务、调用现有只读分析、持久化证据摘要并展示结果。它不调用云端模型、不接受结构纠正、不修改 DOCX，也不生成排版副本。

## 数据流

1. 前端仅接受 `.docx`，文件上限 50 MB。
2. 后端为每次上传创建随机任务目录，并保存独立输入副本。
3. 现有 M3 结构服务以规则模式分析副本；预览最多 20 字。
4. 完整结构报告保存在本地，接口最多返回 100 条异常证据，优先返回明确不一致。
5. 前端明确区分文档块、待确认入口、明确不一致、证据不足和不支持对象。

## 验收条件

- 原始文件字节不变，任务副本与产物位于配置的数据目录。
- 非 DOCX、空文件、超限文件和不安全文件名在分析前拒绝。
- 任务可按 ID 重新读取；路径穿越无效。
- 页面不把启发式分数描述为准确率，不把诊断描述为全文合规证明。
- 后端、前端各自可独立测试和构建。
