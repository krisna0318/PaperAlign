# 核心数据模型

## DocumentBlock

DOCX 中可定位的内容单元。保存原始顺序、语义角色、判定来源、置信度、样式快照和源位置。

## FormatRule

版本化格式要求。每条规则必须包含适用范围、期望值、证据、实现器和验证器。

## DiagnosisIssue

内容块与规则之间的可追溯差异。问题可以是错误、警告或信息，也可以明确标记为未评估。

## AnalysisJob

一次本地分析任务的元数据和产物索引。任务模型不直接保存论文正文。

后端 Pydantic 模型是 M0 的权威定义；`schemas/` 是机器可读导出，前端类型暂时人工镜像。后续由 OpenAPI 自动生成前端类型。
