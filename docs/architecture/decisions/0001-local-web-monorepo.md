# ADR 0001：本地 Web 单仓库

- 状态：已接受
- 日期：2026-09-19

## 决策

MVP 使用 Vue 3 前端与 FastAPI 后端，并放在同一个 Git 仓库中。本地浏览器通过 localhost 调用本机服务。

## 原因

- 降低前后端联调与演示成本；
- 论文默认不离开本机；
- 后续可复用 API 封装桌面应用或 Word Add-in；
- 单仓库便于同步数据契约、测试与版本。

## 后果

- 开发者需要同时具备 Python 和 Node 环境；
- 前后端类型短期存在重复，后续应通过 OpenAPI 生成消除漂移；
- 桌面打包延后到核心流水线稳定之后。
