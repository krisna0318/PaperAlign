# PaperAlign MVP 最终逐项验收清单

日期：2026-09-21。适用版本：0.14.0。

## A. 启动与基础连接

- [ ] 后端 `/health` 显示 `version=0.14.0`、`stage=M7`。
- [ ] 前端能打开，右上角显示后端已连接。
- [ ] 未配置 API Key 时，上传和 Rules-only 诊断仍可正常使用。
- [ ] `.env`、真实论文和 `.paperalign` 产物均未出现在 Git 待提交列表。

## B. 上传与只读分析

- [ ] `.docx` 可以上传；`.doc`、其他扩展名、空文件和超过 50 MB 的文件被明确拒绝。
- [ ] 上传前后原文件的 SHA-256 不变。
- [ ] 页面显示文档块、待确认入口、明确不一致、证据不足和特殊对象数量。
- [ ] 待确认预览不超过 20 字；页面没有把启发式分数称为准确率。
- [ ] 刷新后通过任务 ID 仍能读取本地任务结果。

## C. 结构与规则证据

- [ ] 随机抽查一级至四级标题、正文、图题、表题、参考文献和附录定位。
- [ ] 表格待确认时没有把父表和每个单元格重复列为独立入口。
- [ ] 明确错误、证据不足、不支持对象分别显示，没有被统一伪装成“不通过”。
- [ ] 外国语学院、研究生或非当前届文档不会被宣称适用当前 Profile。

## D. AI 与 Hybrid（可选付费路径）

- [ ] 默认不发送论文片段；只有显式开关与确认参数同时存在才联网。
- [ ] 每个歧义点最多 3 段、每段最多 240 字。
- [ ] 模型建议、规则判断和 Hybrid 决定能分别追踪，模型不直接修改 DOCX。
- [ ] 在 28 项 Gold Set 完成人工标注前，准确率、F1 和 Hybrid 阈值继续显示“未评估/未校准”。

## E. 确定性排版

- [ ] 只有识别出无歧义英文缩略词表时才显示“生成新副本”。
- [ ] 确认卡明确列出顶线 1.5 pt、中线 1 pt、底线 1.5 pt、无竖线。
- [ ] 4 条规则必须整组批准；部分批准、未知规则或未确认结构被拒绝。
- [ ] 宏、嵌入包或 altChunk 等阻断对象存在时不会生成副本。
- [ ] 已存在输出不会被覆盖，原文件字节始终不变。
- [ ] 输出前后内容指纹一致，变更日志恰好对应实际目标和规则。

## F. 最终验证与下载

- [ ] 静态闸门重新验证哈希、内容指纹、包安全和全部已应用规则。
- [ ] `delivery_ready` 只在静态闸门全部通过时为真。
- [ ] 没有 Word 时显示 `unavailable`，仍可下载 DOCX 和人工检查单。
- [ ] 有桌面版 Word 时，勾选探测后能只读打开、重分页并导出 PDF；进程退出后没有残留 WINWORD 进程。
- [ ] 成功导出 PDF 的文案没有宣称“视觉布局已经通过”。
- [ ] 下载的 DOCX 可重新打开，检查单和验证 JSON 与当前任务一致。

## G. 必做 Word 人工抽查

- [ ] 封面、声明、中文/英文摘要、目录、正文和参考文献的分页正确。
- [ ] 更新全部域和目录后，标题、页码、图表编号与交叉引用没有错位。
- [ ] 图、表、公式完整，题注位置正确，跨页表格符合要求。
- [ ] 分节符、页眉页脚、奇偶页和页码起始值正确。
- [ ] 字体没有被本机替换，行距、缩进、段前段后与官方模板一致。
- [ ] 保存关闭后重新打开，再抽查首页、目录页、正文首尾页和参考文献。

## Bug 记录模板

每个问题单独记录：任务 ID、输入文件 SHA-256、操作步骤、预期结果、实际结果、截图、浏览器/Word 版本、是否可稳定复现。不要把真实论文或 API Key 提交到公开 Issue；优先提供脱敏样本和本地报告中的规则 ID/块 ID。
