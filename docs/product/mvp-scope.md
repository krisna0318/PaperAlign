# MVP 范围

## 已确定

- 现有华南农业大学模板，适用于当前应届本科生，排除外国语学院和研究生；先贯通这一模板，不扩展学院定制；
- Windows 本地运行；
- 用户稿件只支持 `.docx`；
- 原文件永不覆盖；
- 无 API Key 时规则模式仍可运行；
- 输出 DOCX、诊断报告、改动摘要和未解决事项；
- 同一数据集比较 Prompt-only、Rules-only 与 Hybrid。

## 暂不支持

- 任意学校自动适配；
- 旧 `.doc` 用户稿件；
- PDF、扫描件、OCR 和 LaTeX；
- 论文写作、润色、查重和参考文献真实性检查；
- 账号、多端同步和多人协作。

## 里程碑

1. M0：仓库、环境与数据模型；
2. M1：DOCX 只读画像；
3. M2：华农规则 Profile（核心配置已完成，确认与验证持续进行）；
4. M3：Rules-only 结构识别（核心流程已完成）；
5. M4：Prompt-only 与 Hybrid 基线；
6. M5：只读诊断 UI；
7. M6：确定性排版；
8. M7：Word 完成与验证。
